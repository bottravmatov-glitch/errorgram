ERRORGRAM — прототип v0.3

Что добавлено:
- адаптивный интерфейс для ПК и телефона (PWA)
- демонстрационные чаты, поиск, создание демо-чата
- локальное сохранение демо-сообщений
- экран аккаунта с входом и регистрацией email + пароль
- подготовлен клиент Supabase Auth; заработает после настройки проекта
- офлайн-кэш PWA

ВАЖНО: реальные чаты пока демонстрационные и не доставляются пользователям. Не вводи настоящие пароли, пока не настроен свой Supabase-проект.

Настройка бесплатной авторизации (нужен аккаунт Supabase):
1. Создай проект на https://supabase.com/ (бесплатный тариф).
2. В Project Settings -> API скопируй Project URL и anon/public key. НЕ используй service_role key.
3. config.js уже заполнен Project URL и твоим Publishable key. Не заменяй его secret/service_role ключом.
4. Authentication -> Providers -> Email: оставь Email включённым.
5. Для входа без email-кодов отключи Confirm email (название настройки может отличаться в интерфейсе). Это снижает защиту от регистрации чужой почты; используй осознанно.
6. Размести папку на HTTPS-хостинге, чтобы PWA и service worker работали. Для установки: Chrome/Edge -> меню -> Install app; Android Chrome -> Install app/Add to Home screen.

Локальная проверка: index.html можно открыть напрямую для интерфейса; авторизация требует HTTPS/сервер и настройки.
